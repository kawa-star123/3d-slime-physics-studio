# うごけスライム（うごスラ）

ふと目の前にあるペットボトルを投げつけてスライムみたいな挙動をしたらどうなるだろうと思いついて、このソフトウェア、「うごけスライム（うごスラ）」を作成しました。なんにでもスライムにできたらいいなという子ども時代の願望をかなえてくれるところが私は好きです。

見た目はかなりクセの強いレトロなデザインにしていますが、これは初代ネット（1990年代後半の Web 1.0）の雰囲気が好きだったからに過ぎないです。レトロで作ってみたかったのです。それだけです。

## このアプリについて

手持ちの 3D モデルや平面のイラスト画像（正面・背面・左右・上面）を読み込んで厚みのある 3D 立体を生成し、その表面をマウスでつまんで無限に引っ張れるデスクトップアプリ（Electron + Three.js）です。  
見た目は 90 年代のホームページや Windows 95 のようにチープで懐かしい雰囲気ですが、中身はバネ質点系のソフトボディ物理演算と、エネルギー・勾配・ヘッセ行列条件数をリアルタイムに監視するテレメトリを備えています。

## セットアップと起動

```bash
npm install
npm start
```

`npm start` でデスクトップウィンドウが起動します。起動直後は床グリッドと角丸キューブ型の見本スライムが表示されるため、ファイルを用意しなくてもすぐにつかんで引っ張ったり、視点を回したりして遊べます。

### 実行ファイル（.exe / .app）のビルド

```bash
npx electron-builder          # 実行中の OS 向け
npx electron-builder --win    # Windows (NSIS インストーラ .exe)
npx electron-builder --mac    # macOS (.dmg / .app)
```

ビルドした成果物は `dist/` フォルダに出力されます。

## 操作方法

### マウス・キーボード操作

| 操作 | 動作 |
| --- | --- |
| **左ドラッグ** | メッシュ表面をつまんで引っ張る（ポインターロックにより画面端で止まらず無限に引っ張れます。押しっぱなしで静止しても牽引を維持し、離すと弾性エネルギーが解放されて振動します） |
| **Shift + 左ドラッグ** | カメラ回転 |
| **右ドラッグ / 中ドラッグ** | カメラの平行移動 |
| **ホイール** | ズーム |
| **S キー** | 時間の停止 / 再開（時間を止めたままカメラを回して好きな角度で撮影できます） |

※カメラ操作と引っ張り操作はクリック（`pointerdown`）時点の修飾キーで排他的に決まるため、ドラッグ途中に Shift キーを押し離ししてもモードは切り替わりません。

### 画面上のボタン・パネル

| 操作 | 動作 |
| --- | --- |
| **視点リセット** | カメラ位置を初期状態に戻す |
| **固定モード / 重力モード** | 物理挙動の切替。既定の「固定モード」は空中に固定され床の当たり判定がありません（下方向にも引っ張れます）。「重力モード」にすると重力が働き、床に落下・反発します |
| **ソリッド / ワイヤーフレーム / ネットワーク** | 表示モード切替。「ネットワーク」は発光ドットと細いバネ線で表示され、ひずみが大きい部分ほど赤く変化します |
| **AM / PM** | ライト / ダークテーマ切替。3D 空間の背景・グリッド・星空演出も連動します |
| **JP / EN** | 画面上の全テキストの日本語 / 英語切替（設定は自動保存されます） |
| **時間停止 (S)** | シミュレーションの時間停止・再開 |
| **スクリーンショット** | 現在の 3D ビューを PNG 画像として保存（時間停止中も撮影可能） |
| **`<` / `>` ボタン** | 左設定パネルの開閉。閉じると 3D ビューポートが画面いっぱいに広がります |
| **すべて初期化** | 確認ダイアログで OK を押すと、読み込んだデータと全パラメータを初期状態（見本スライム）へ戻す |

## 3D モデルからの生成

起動時は「3Dモデルから生成」タブが開いています。手持ちの 3D モデルファイルを枠内または 3D ビューポートへドラッグ＆ドロップ（またはクリックで選択）するだけでソフトボディ化されます。

- **対応フォーマット**：`obj` / `glb` / `gltf` / `stl` / `ply` / `fbx` / `dae`（拡張子から自動判別します）
- **色・テクスチャの反映**：
  - `obj` は `.mtl` ファイルやテクスチャ画像と一緒に複数選択（またはドロップ）すると色が付きます（後から追加することも可能）。
  - `gltf` が外部データ（`.bin` や画像）を必要とする場合は不足ファイル名が表示されるため、一緒に選択してください。
  - `glb` / `gltf` / `ply` は頂点カラー・基本色・テクスチャに対応しています（`stl` は色情報を持たないため標準色になり、Z 上向き座標は Y 上向きへ自動補正します）。
  - `fbx` / `dae` は Three.js の拡張ローダーを使用するため、初回読み込み時のみネットワーク接続が必要です。
  - 色の優先順位は「テクスチャ > 頂点カラー > 基本色（Kd）」です。
- **バネ網と自動最適化**：
  - 全エッジの「構造バネ」、隣接三角形の対向頂点を結ぶ「せん断バネ」、各頂点から内向きにレイを飛ばして反対側の表面と結ぶ「内部支持バネ」（最大 1,500 本）を自動生成します。
  - 頂点数が 5,000 を超えると注意を表示し、12,000 を超える場合は頂点クラスタリングで約 8,000 頂点へ自動的に間引きます。
  - 閉じたメッシュには体積保持（ガス圧モデル）が働き、穴のあいた開いたメッシュでは体積保持を自動で無効化します。

## 画像からの 3D 立体化

「画像から生成」タブでは、正面（Front）枠に 1 枚画像を入れるだけで立体化されます。さらに背面（Back）や「その他の面」（右側面・左側面・上面）を追加すると、最大 5 視点から削り出した精密な立体になります。縦長・横長の画像も自動クロップせず、縦横比と共通スケールを保ったまま立体化します。

1. **シルエット抽出**：透過画像（アルファ値 250 未満の画素を含む場合）はアルファ値で輪郭を判定し、不透明画像は四隅の色を基準にした塗りつぶし（Flood Fill）で背景のみを除去します（内側の白いパーツは消えずに残ります）。
2. **1 枚（または同一平面）のとき：レリーフ立体化**：輝度を 2〜98 パーセンタイルで正規化して擬似深度 `h(x, y)` を作り、シルエット内のチャンファー距離変換による丸み `r(x, y)` と組み合わせて厚みを決定します。
   ```text
   T(x, y) = Hz * (0.2 + 0.8 * clamp((1 - α) * r + α * h))
   ```
3. **2 枚以上のとき：多視点シルエット彫刻（Visual Hull）**：各視点の正射影シルエットを 3D ボクセル空間で交差させ、さらに各視点の擬似深度で手前側を浅く彫刻します。
4. **メッシュ化と投影シェーダー**：3×3×3 ボックスフィルタで密度場にした後、Surface Nets で四角形メッシュを抽出し Taubin スムージングで平滑化します。テクスチャは初期座標系から投影するシェーダーで貼り付けるため、スライムが伸びても模様が綺麗に追従します。

## 物理モデルとパラメータ

### 運動方程式と数値積分

各頂点の質量を $m = 1$ とし、サブステップ $\Delta t = 1/360$ 秒の**半陰的オイラー法（Semi-Implicit Euler）**で時間発展を計算しています。

$$E = \sum \frac{1}{2} k_s (L - L_0)^2 + \frac{1}{2} k_r \sum \Vert{}\mathbf{x} - \mathbf{x}_0\Vert{}^2 + U_{\text{vol}}(V)$$

$$\mathbf{F} = -\nabla E, \qquad m \mathbf{x}'' = -\nabla E - c \mathbf{x}' + m \mathbf{g} + \mathbf{F}_{\text{grab}}$$

- **バネ網の剛性比**：構造 `1.0` / せん断 `0.45` / 曲げ `0.2` / 内部支持 `0.3`
- **把持力 $\mathbf{F}_{\text{grab}}$**：つかんだ頂点から半径 $R$ 以内の頂点へ、滑らかな距離重み $(1 - d^2/R^2)^2$ と法線ゲートを掛けて毎サブステップ牽引力を加えます。

### スライダーパラメータ一覧

| パラメータ | 説明 |
| --- | --- |
| **剛性係数 $k$** | バネ全体の硬さのスケール |
| **減衰係数 $c$** | 速度に比例する抵抗力。小さいほどプルプルと長く振動します |
| **重力加速度 $g$** | 重力モード時に下向きへ引っ張る重力の強さ |
| **把持影響半径 $R$** | マウスでつまんだ周囲を一緒に引きずる範囲 |
| **体積保持係数 $\beta$** | ガス圧モデルによる内圧の強さ。大きいほど潰れにくくなります |
| **形状復元比 $k_r / k$** | 元の 3D 形状へ戻ろうとする復元バネの強さ |
| **ボクセル解像度 $N$** | 画像から立体化するときの最長軸の分割数（頂点数は $N^2$ にほぼ比例） |
| **背景しきい値** | 不透明画像の背景判定の感度 |
| **レリーフ強度 $\alpha$** | 画像の明暗による擬似深度を厚みや彫刻に反映する割合 |
| **押し出し厚み** | 画像が 1 枚（または同一平面のみ）のときの未指定軸の厚み比率 |
| **深度コントラスト** | 輝度から擬似深度を作るときのコントラスト |

### テレメトリ（右上カウンター）

| 項目 | 内容 |
| --- | --- |
| **総弾性エネルギー $E$** | バネ・復元バネ・体積保持項のポテンシャルエネルギー合計（重力による垂れ下がり分も含まれるため静止時も 0 になりません） |
| **最大勾配ノルム $\max \Vert{}\nabla E\Vert{}$** | 全頂点の中で最も強い不均衡な力の大きさ |
| **ヘッセ条件数 $\kappa(H)$** | 剛性行列の固有値比 $\lambda_{\max} / \lambda_{\min}$ を行列フリー法（$\lambda_{\max}$: べき乗法、$\lambda_{\min}$: 共役勾配法による逆反復）で推定した数値計算の硬さの指標 |
| **把持力 $\Vert{}F_{\text{grab}}\Vert{}$** | マウスで引っ張っている頂点に働く牽引力の大きさ |

## デザイン仕様（1990 年代後半 Web 1.0 スタイル）

- **ライトモード（AM）**：Lycos / Apple / AOL 風の白ベース・赤いサイドバー・黒いヘッダーとオレンジの立体ボタン・青い下線リンク・金の星付きタイトルバー。3D ビューは Windows 95 デスクトップ風のティール色（`#008080`）にネオングリーンのグリッドと原色 XYZ 座標軸を配置。
- **ダークモード（PM）**：90 年代宇宙サイト風の星空背景・紺のテクスチャパネル・クローム調の枠と金色の選択ハイライト・遠くに浮かぶ惑星。
- **UI パーツ**：角丸をすべて廃した `outset` / `inset` の立体ボタン、レインボーグラデーションの区切り線、黒地にネオングリーン（`#00FF00`）のアクセスカウンター風数値表示を採用しています。

## Three.js の読み込みとオフライン動作

`index.html` の import map から CDN 版の Three.js (r160) を参照しつつ、`main.js` では静的 `import` を使わず **unpkg CDN → jsDelivr CDN → `./node_modules` → `./vendor/three.module.js`** の順に動的読み込みを行います。ネットワークに接続できない環境でも、ローカルにファイルがあれば自動フォールバックして起動します。
